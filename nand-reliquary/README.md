# Midnight NAND Reliquary — forensics (work in progress)

Dump: 416 pages × (256 data + 16 OOB), 8 pages/block, 52 blocks.

## What is solved
| Item | Finding |
|------|---------|
| Noise pages | `random.Random(0x15081947)` (the date 15-08-1947 as BCD); per page one `random()` (erased?) + 272 × `randint(0,255)`. Regenerated byte-exact, no flips. |
| Bad blocks | 3, 17, 41 — OOB starts `BB` (rest of the page is noise). |
| Fake strings | Pages 3/5, 11/0, 27/5 (OOB `FK`). |
| Reliquary pages | OOB magic `AZ`: 8/3, 16/2, 36/5, 40/5. |
| OOB layout | `[4]` payload length, `[5]` seq (1/3), `[6:10]` CRC32-BE of stored payload, `[10:16]` unexplained. |
| Filler | `random.Random(1337*page + lp).randint(0,255)` after the payload (lp 0 / 1). |
| Bit flip | page 36/5 byte 2 bit 1 (found via the CRC32). |
| Stale copies | seq-3 copy = seq-1 copy XOR `0xa7`. |
| Record | `MNND` + u16be `0x0034` + 52-byte body |

## Ruled out for the body cipher
Repeating XOR/sub keys up to 26 bytes; date/strings via MD5/SHA*/RC4/AES/ChaCha;
Python `random` XOR keystreams for **every 32-bit int seed** (randint, randbytes,
getrandbits(8); start offsets 0–24; XOR and subtraction); NumPy-style MT seeding;
any window of the noise RNG; LCG/LFSR/xorshift/PCG families; bit permutations.
